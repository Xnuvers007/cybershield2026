🔓 AUTHENTICATION FAILURES — A07:2026

Cara Kerja Auth Failures

Brute force, credential stuffing, session fixation — kelemahan di proses login dan session management.

← IDOR🏠 Semua AnimasiCSRF →
1
🎯 Target: Halaman login tanpa proteksi
Login form tanpa rate limiting, tanpa CAPTCHA, tanpa account lockout. Tidak ada limit percobaan login.
2
🤖 Brute Force Attack
Penyerang menggunakan tools (Hydra, Burp) untuk mencoba ribuan password per menit:
admin:password123 → ❌
admin:admin123 → ❌
admin:Adm1n@2026 → ✅ BERHASIL!
3
📋 Credential Stuffing
Menggunakan username+password yang bocor dari breach lain. 60% user pakai password sama di banyak situs!
4
🔒 Session Fixation/Hijacking
Session ID tidak di-regenerate setelah login → penyerang yang mengetahui session ID bisa mengambil alih session.
5
🕵️ User Enumeration
Pesan error berbeda: "Username tidak ditemukan" vs "Password salah" → penyerang tahu username mana yang valid.
6
💥 Account Takeover massal
Ribuan akun diambil alih. Financial fraud, data theft, identity theft — kerugian besar bagi user dan organisasi.

⚠️ RENTAN
if ($pass === "admin123") { $_SESSION['user'] = $username; // ⚠️ Session ID tidak di-regenerate // ⚠️ Tidak ada rate limiting // ⚠️ "Username tidak ditemukan" // vs "Password salah" (enumeration) }
✅ AMAN
if (password_verify($pass, $hash)) { session_regenerate_id(true); $_SESSION['login_time'] = time(); } // ✅ Rate limit: max 5 attempts // ✅ Account lockout 15 min // ✅ Generic: "Invalid credentials" // ✅ MFA (2FA) enabled

💀 Dampak

  • Mass account takeover
  • Financial fraud
  • Identity theft
  • Data breach via admin account

🛡️ Pencegahan

  • Rate limiting + account lockout
  • MFA / 2FA
  • session_regenerate_id() setelah login
  • Generic error messages
  • Password policy (min 12 char)
