📤 FILE UPLOAD → WEBSHELL

Cara Kerja File Upload Attack

Upload file PHP/JSP berbahaya (webshell) → eksekusi perintah server langsung dari browser.

← XXE🏠 Semua AnimasiBroken Access →
1
🔍 Menemukan form upload
Form upload avatar, dokumen, attachment — fitur yang menyimpan file ke server web yang bisa diakses publik.
2
🐚 Membuat webshell PHP
File PHP sederhana yang mengeksekusi perintah OS:
<?php system($_GET['cmd']); ?>
Disimpan sebagai: shell.php.jpg (bypass extension check)
3
📤 Upload file dengan bypass
Bypass validasi: ubah Content-Type header, gunakan double extension (shell.php.jpg), null byte (shell.php%00.jpg), case manipulation (shell.pHp).
4
🌐 Akses webshell via URL
File tersimpan di directory yang bisa diakses web:
https://target.com/uploads/shell.php?cmd=whoami
5
💀 Remote Code Execution via webshell
Penyerang bisa menjalankan perintah apapun: ?cmd=cat /etc/passwd, ?cmd=ls -la, ?cmd=wget backdoor.
6
💥 Persistent backdoor access
Webshell = persistent backdoor. Penyerang bisa kembali kapan saja. Install reverse shell, dump database, pivot ke server lain.

⚠️ RENTAN
$name = $_FILES['file']['name']; move_uploaded_file( $_FILES['file']['tmp_name'], "uploads/$name" ); // Bypass: shell.php.jpg, shell.pHp // Webshell: <?php system($_GET['cmd']);
✅ AMAN
$finfo = new finfo(FILEINFO_MIME_TYPE); $mime = $finfo->file($tmp); $allowed = ['image/jpeg', 'image/png']; if (!in_array($mime, $allowed)) die("Tipe tidak diizinkan"); $newName = bin2hex(random_bytes(16)); move_uploaded_file($tmp, "../storage/$newName.jpg"); // Di luar web root + random name!

💀 Dampak

  • Remote Code Execution via webshell
  • Persistent backdoor access
  • Full server compromise
  • Lateral movement ke jaringan

🛡️ Pencegahan

  • Validasi magic bytes (bukan extension)
  • Random filename (UUID/hex)
  • Simpan di luar web root
  • Disable PHP execution di uploads/
