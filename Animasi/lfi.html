📁 LOCAL FILE INCLUSION (LFI)

Cara Kerja Local File Inclusion

Membaca file sensitif di sistem server dengan manipulasi parameter path directory traversal (../../).

← Command Inj.🏠 Semua AnimasiRCE →
1
🔍 Menemukan fitur include file
Aplikasi web memuat halaman menggunakan parameter: ?page=about
2
💉 Menyisipkan Path Traversal
Attacker mencoba mundur ke root directory: ?page=../../../../etc/passwd
3
⚙️ Server memproses path
Fungsi include() menerima input dan menyatukannya: pages/../../../../etc/passwd
4
📄 File OS terbuka
Directory traversal melewati batasan folder aplikasi dan mencapai file konfigurasi sistem operasi.
5
💥 Konten terekspos
Isi file /etc/passwd (atau konfigurasi database) ditampilkan di layar browser attacker.
1 / 5
⚠️ RENTAN
$file = $_GET['page']; // Berbahaya: menyertakan file langsung include("pages/" . $file . ".php");
✅ AMAN
$file = $_GET['page']; $allowed = ['home', 'about', 'contact']; // Validasi Whitelist! if (in_array($file, $allowed)) { include("pages/" . $file . ".php"); }

💀 Dampak

  • Membaca /etc/passwd
  • Source code disclosure
  • Membaca config database
  • Eskalasi menjadi RCE via log poisoning

🛡️ Pencegahan

  • Whitelist parameter include
  • Hindari input user di filesystem API
  • Gunakan open_basedir di PHP
  • Non-root web user privilege
⚠️ EDUKASI ONLY
