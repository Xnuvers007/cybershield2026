💀 REMOTE CODE EXECUTION (RCE)

Cara Kerja Remote Code Execution

Attacker bisa menjalankan kode atau perintah apa pun langsung di server. Level tertinggi dari kompromi sistem.

← LFI🏠 Semua AnimasiSSRF →
1
🔍 Menemukan fitur eksekusi kode
Aplikasi menggunakan fungsi seperti eval(), unserialize(), atau fitur upload yang tidak aman.
2
💉 Mengirim payload RCE
Attacker mengirim payload: ?calc=phpinfo(); system('id');
3
⚙️ Server mengeksekusi langsung
Bahasa pemrograman (PHP/NodeJS/Python) menjalankan payload sebagai instruksi asli.
4
📡 Attacker memasang Reverse Shell
Attacker mengirimkan script untuk membuka koneksi balik (shell) ke komputernya.
5
💥 Server Takeover
Attacker kini memiliki akses Terminal/Command Prompt penuh ke server target.
1 / 5
⚠️ RENTAN
$math = $_GET['calc']; // Fungsi berbahaya: eval, exec, system eval("return $math;");
✅ AMAN
// Jangan pernah menggunakan eval() // Gunakan math parser library khusus $parser = new MathParser(); echo $parser->evaluate($_GET['calc']);

💀 Dampak

  • Server Takeover 100%
  • Malware/Ransomware installation
  • Pencurian seluruh database
  • Lateral movement

🛡️ Pencegahan

  • Hindari fungsi eval/system
  • Gunakan parser khusus
  • Batasi permission eksekusi
  • Monitor server anomaly
