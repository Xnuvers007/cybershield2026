💉 SQL INJECTION — A03:2021

Cara Kerja SQL Injection

Menyisipkan perintah SQL berbahaya ke dalam input aplikasi untuk memanipulasi database.

🏠 Semua AnimasiReflected XSS →
1
👤 User mengakses form login
Halaman login memiliki input username dan password yang berinteraksi dengan database.
2
💉 Attacker memasukkan payload SQL
Attacker mengetikkan: admin' OR '1'='1 di kolom username.
3
⚙️ Aplikasi menyusun query string
Query menjadi: SELECT * FROM users WHERE username = 'admin' OR '1'='1'
4
🧠 Database mengeksekusi query
Kondisi '1'='1' selalu BENAR, sehingga database mengabaikan pengecekan password.
5
🔓 Bypass otentikasi berhasil
Attacker berhasil login sebagai admin tanpa mengetahui password yang sebenarnya.
1 / 5
⚠️ RENTAN
$user = $_POST['username']; $query = "SELECT * FROM users WHERE username = '$user'"; $db->query($query);
✅ AMAN
$stmt = $db->prepare( "SELECT * FROM users WHERE username = ?" ); $stmt->bind_param("s", $_POST['username']); $stmt->execute();

💀 Dampak

  • Data breach massal
  • Bypass otentikasi (admin login)
  • Ubah atau hapus data
  • Remote Code Execution (RCE)

🛡️ Pencegahan

  • Gunakan Prepared Statements
  • Validasi Input (Whitelist)
  • Prinsip Least Privilege di DB
  • Gunakan ORM yang aman
