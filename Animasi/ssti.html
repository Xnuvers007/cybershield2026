💻 SSTI — SERVER-SIDE TEMPLATE INJECTION

Cara Kerja SSTI

Penyerang memasukkan payload template berbahaya yang akan dieksekusi secara native oleh mesin template server.

🏠 Semua Animasi
1
🧩 Mesin Template
Aplikasi web menggunakan Template Engine (seperti Twig, Jinja2, Smarty) untuk menghasilkan HTML dinamis.
2
⚠️ Implementasi yang Buruk
Developer menyisipkan input pengguna *langsung* ke dalam struktur template mentah sebelum diproses oleh engine, alih-alih melewatinya sebagai variabel.
3
💉 Payload Injeksi
Penyerang mengirim input berupa tag eksekusi template, misal: {{ 7 * 7 }} atau {{ system('id') }}.
4
⚙️ Parsing & Eksekusi Server
Template Engine melihat tag `{{ ... }}` dan mengiranya sebagai kode logic internal, lalu mengeksekusinya di sisi server.
5
💥 Remote Code Execution
Sistem mengembalikan hasil evaluasi matematika (`49`) atau bahkan output dari perintah sistem operasi server. Server berhasil dibobol penuh!
1 / 5
⚠️ RENTAN
<?php // Input dimasukkan sebagai bagian DARI template! $input = $_GET['name']; $template = "Halo " . $input; // Eval atau Engine memproses string mentah ini $html = $twig->createTemplate($template)->render(); ?>
✅ AMAN
<?php // Template statis (aman) $template = "Halo {{ nama }}"; // Input dikirim sebagai variabel context $html = $twig->render('template.html', [ 'nama' => $_GET['name'] ]); ?>

💀 Dampak

  • Remote Code Execution (RCE)
  • Pembacaan file konfigurasi server
  • Eskalasi hak istimewa (Privilege Escalation)

🛡️ Pencegahan

  • Jangan pernah menggabungkan input pengguna ke dalam string template mentah
  • Giring input pengguna hanya sebagai parameter/variabel konteks
  • Gunakan Sandboxing jika memungkinkan
