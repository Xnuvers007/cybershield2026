🪞 REFLECTED CROSS-SITE SCRIPTING

Cara Kerja Reflected XSS

Script berbahaya dipantulkan (reflected) dari server ke browser melalui parameter URL atau input pencarian.

← SQL Injection🏠 Semua AnimasiStored XSS →
1
🔍 Fitur pencarian rentan
Aplikasi menampilkan input pencarian langsung ke halaman web tanpa sanitasi.
2
🔗 Attacker membuat link jebakan
Membuat URL: ?search=<script>steal(document.cookie)</script>
3
📧 Mengirim link ke korban
Attacker mengelabui korban untuk mengklik link tersebut via email atau chat.
4
🌐 Server memantulkan script
Server merender halaman dengan script berbahaya dimasukkan langsung ke HTML.
5
💥 Script dieksekusi di browser korban
Browser korban menjalankan script, mencuri session cookie dan mengirimkannya ke attacker.
1 / 5
⚠️ RENTAN
$query = $_GET['search']; echo "Hasil pencarian untuk: " . $query;
✅ AMAN
$query = $_GET['search']; echo "Hasil pencarian untuk: " . htmlspecialchars($query, ENT_QUOTES, 'UTF-8');

💀 Dampak

  • Pencurian Session (Cookie Theft)
  • Keylogging
  • Redirection ke phishing
  • Aksi tidak sah atas nama korban

🛡️ Pencegahan

  • Context-Aware Output Encoding
  • Gunakan htmlspecialchars()
  • Terapkan Content Security Policy (CSP)
  • HttpOnly Cookie Flag
