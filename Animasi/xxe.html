📄 XML EXTERNAL ENTITY (XXE)

Cara Kerja XML External Entity

Mengeksploitasi parser XML untuk membaca file lokal atau SSRF dengan menyisipkan entity eksternal.

← SSRF🏠 Semua AnimasiFile Upload →
1
🔍 Menemukan endpoint penerima XML
Aplikasi menerima input dalam bentuk dokumen XML (SOAP, SAML, SVG, atau Docx).
2
💉 Menyisipkan External Entity
Attacker membuat payload XML khusus: <!ENTITY xxe SYSTEM "file:///etc/passwd">
3
⚙️ Server mem-parsing XML
Parser XML yang rentan secara otomatis memproses entitas eksternal tersebut dan membaca file.
4
📄 XML tersusun ulang
Isi file /etc/passwd dimasukkan ke dalam elemen dokumen XML di memori server.
5
💥 Ekstraksi data
Aplikasi mengembalikan pesan error atau respons normal yang mengandung isi file rahasia server.
1 / 5
⚠️ RENTAN
$xml = file_get_contents('php://input'); // Parser XML dikonfigurasi TIDAK AMAN libxml_disable_entity_loader(false); $doc = new DOMDocument(); $doc->loadXML($xml);
✅ AMAN
$xml = file_get_contents('php://input'); // Disable external entities libxml_disable_entity_loader(true); $doc = new DOMDocument(); $doc->loadXML($xml);

💀 Dampak

  • LFI (Membaca file server)
  • SSRF internal
  • Denial of Service (Billion Laughs)
  • Data exfiltration via OOB

🛡️ Pencegahan

  • Matikan External Entity Parsing
  • Gunakan format JSON daripada XML
  • Update library parser XML
  • Gunakan WAF
